##Concepts

- busybox : a pack of tools
- AS : *Autonomous System* , one unique network you decide how to administrate (you own it)
- ASN : *Autonomous System Number*, the world number identification for said AS.
- BGP : *Border gateway Protocol* , is what decices witch route data **between** AS
- IGP : *Interior Gateway Protocol* , is what decides how to route data **inside** AS
- OSPFD : *Open Shortest Path First*  , a type of IGP , 
- IS-IS : *Intermediate System to Intermediate System* 
- FRR : FRRouting , a free software for routing , frr is the descendant of zebra
